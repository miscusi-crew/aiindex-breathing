# Breathing Exercise

Guided breathing: box, 4-7-8 and calm breathing.

Follow the circle as it grows and shrinks to slow your breathing.

- Box breathing, 4-7-8 and simple calm breathing
- Choose how many minutes

## Run it

Open `app/index.html` in a browser. There's no build step and no dependencies: plain HTML, CSS and JavaScript.

On AI Index it runs in the browser with **Run here** (Offline). `aiindex.json` tells AI Index which
folder to serve; its token links this repo to the listing.
